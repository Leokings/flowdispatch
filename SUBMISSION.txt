TITLE
FlowDispatch — Consensus Compatibility Max-Flow

DESCRIPTION
FlowDispatch is a reusable GenLayer intelligent contract for allocating multi-unit capacity to demand when compatibility depends on natural-language profiles. Validators independently derive a closed bipartite compatibility graph, then deterministic contract code runs a bounded augmenting-path max-flow algorithm and records allocations, total flow, and unmet demand. The reviewed version normalizes leader output before exact comparison, rejects invalid role identities, and makes missing reads fail closed. GenVM lint, strict type checking, 8 direct tests, a five-validator GLSim flow, finalized StudioNet execution, latest-final readback, and exact deployed-source verification all pass.
